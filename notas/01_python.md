# Python

Python é uma linguagem de programação de alto nível criada por Guido van Rossum e lançada em 1991. Seu nome é uma homenagem ao grupo de comédia britânico Monty Python, e não à cobra.

A linguagem é conhecida pela sintaxe limpa e pelo uso obrigatório de indentação para delimitar blocos de código. Python é interpretada, de tipagem dinâmica e suporta múltiplos paradigmas: orientado a objetos, funcional e procedural.

O gerenciador de pacotes padrão é o pip, que instala bibliotecas do repositório PyPI (Python Package Index). Ambientes virtuais, criados com "python -m venv", isolam as dependências de cada projeto.

Python é muito usado em ciência de dados (pandas, NumPy), inteligência artificial (PyTorch, TensorFlow), desenvolvimento web (Django, Flask, FastAPI) e automação de tarefas. O Python 2 teve seu suporte encerrado em 1º de janeiro de 2020.
