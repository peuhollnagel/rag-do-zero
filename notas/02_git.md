# Git

Git é um sistema de controle de versão distribuído criado por Linus Torvalds em 2005, originalmente para gerenciar o desenvolvimento do kernel do Linux.

Diferente de sistemas centralizados como o SVN, no Git cada desenvolvedor possui uma cópia completa do repositório, incluindo todo o histórico. Isso permite trabalhar offline e torna o sistema mais resiliente.

Comandos essenciais:
- git init: cria um novo repositório
- git add: adiciona arquivos à área de staging
- git commit: registra as alterações no histórico
- git branch: cria ou lista ramificações
- git merge: une duas branches
- git push e git pull: enviam e recebem alterações de um repositório remoto

Plataformas como GitHub, GitLab e Bitbucket hospedam repositórios Git e adicionam recursos como pull requests, revisão de código e integração contínua. O GitHub foi adquirido pela Microsoft em 2018 por 7,5 bilhões de dólares.
