# SQL

SQL (Structured Query Language) é a linguagem padrão para gerenciar e consultar bancos de dados relacionais. Foi desenvolvida na IBM no início dos anos 1970 por Donald Chamberlin e Raymond Boyce, com base no modelo relacional proposto por Edgar F. Codd.

Em um banco relacional, os dados são organizados em tabelas compostas por linhas e colunas. As tabelas se relacionam por meio de chaves primárias e chaves estrangeiras.

Os comandos SQL se dividem em categorias:
- DDL (definição): CREATE, ALTER, DROP
- DML (manipulação): INSERT, UPDATE, DELETE
- DQL (consulta): SELECT
- DCL (controle): GRANT, REVOKE

O comando JOIN combina linhas de duas ou mais tabelas. Os tipos mais comuns são INNER JOIN, LEFT JOIN, RIGHT JOIN e FULL OUTER JOIN.

Sistemas populares incluem PostgreSQL, MySQL, SQLite, Microsoft SQL Server e Oracle Database. O SQLite é notável por ser um banco embutido em um único arquivo, presente em praticamente todos os smartphones.
